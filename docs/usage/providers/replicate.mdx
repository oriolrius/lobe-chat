# Using Replicate in LobeChat

<Image alt={'Using Replicate in LobeChat'} cover src={'https://github.com/user-attachments/assets/24a3320b-5981-4e4e-b874-17d587445d48'} />

[Replicate](https://replicate.com/) is a platform that makes it easy to run machine learning models in the cloud. It hosts state-of-the-art image generation models from Black Forest Labs including FLUX and FLUX 2 series. This document will guide you on how to use Replicate in LobeChat:

<Steps>
  ### Step 1: Obtain Replicate API Token

  - Create a [Replicate account](https://replicate.com/).
  - Navigate to [API tokens page](https://replicate.com/account/api-tokens) and click **Create token** to generate a new API token.
  - Copy the generated API token and keep it secure.

  ### Step 2: Configure Replicate in LobeChat

  - Visit the `Settings` page in LobeChat.
  - Under **AI Service Provider**, locate the **Replicate** configuration section.

  - Paste the API token you obtained.
  - Choose a Replicate model (e.g. `FLUX 1.1 Pro`, `FLUX 2 Pro`) for image generation.

  <Callout type={'warning'}>
    During usage, you may incur charges according to Replicate's pricing policy. Please review Replicate's
    official pricing before heavy usage.
  </Callout>
</Steps>

You can now use Replicate's advanced image generation models directly within LobeChat to create stunning visual content.
